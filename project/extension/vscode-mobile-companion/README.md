# VS Code Mobile Companion

Desktop-side VS Code extension for the mobile companion rewrite.

## Current capabilities

- local desktop API
- workspace discovery
- pairing bootstrap
- relay connection
- prompt submission into VS Code chat

## Commands

- `Codr Companion: Start Pairing`
- `Codr Companion: Connect Relay`
- `Codr Companion: Show Status`
- `Codr Companion: Send Prompt`
- `Codr Companion: Start New Chat`
